Your agent gets a permission slip, not your keys.

Today an AI agent either holds your credentials — full, permanent power — or it can't act at all. Mandate is the middle: authority that is scoped, capped, expiring and revocable, with every action recorded on-chain.

The problem

Agents act. Nobody can say what they were allowed to do.

The failure mode is not a rogue intelligence. It's that there was never a limit to exceed, and no record to check afterwards.

01

All or nothing

You hand over a key and hope, or you don't delegate at all. There is no way to grant one narrow power and keep the rest.

02

No record

When something goes wrong, the only account of what happened is the agent's own logs — written by the party you're investigating.

03

Revocation is manual

Rotating a key to stop one agent breaks every other integration using it. There's no way to withdraw a single permission instantly.

How it works

A mandate is a signed, bounded grant of authority.

The principal grants it. The agent acts inside it. The chain records both.

01 — GRANT

Set the box

An asset, a spending cap, an expiry and an action scope. The principal is the only address that can change or revoke it.

02 — ACT

Stay inside it

The agent records each action against the mandate. Outside the cap, past the expiry, or after revocation, the call reverts.

03 — REVOKE

End it instantly

One transaction from the principal. Revocation is final by design — a leash you can quietly re-attach is not a leash.

The contract

Four writes. That's the whole surface.

Solidity 0.8.24, no dependencies, no upgradeability. It holds no funds in this version — it is a ledger of authority, so there is nothing to drain.

    address agent, address asset,

) external returns (uint256 mandateId)

function recordAction(
    uint256 mandateId, uint96 amount,
    bytes32 actionHash, string memo
) external                       // reverts outside the box

function revoke(uint256 mandateId) external   // principal only, final
function extend(uint256 mandateId, uint96 cap, uint64 expiry) external
Every refusal is explicit
NotAgent · MandateRevoked · MandateExpired · CapExceeded(requested, remaining)
The record
ActionRecorded(mandateId, agent, amount, spentAfter, actionHash, memo) — a public event per action
Remaining allowance
remaining() returns 0 for revoked or expired mandates, so a dead mandate can't be mistaken for a live one
